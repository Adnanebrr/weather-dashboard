# 🌤️ Weather Dashboard

A beautiful, responsive weather dashboard built with React and Tailwind CSS that displays current weather conditions and 5-day forecasts for any city worldwide.

## ✨ Features

- **Real-time Weather Data** - Current temperature, humidity, wind speed, and pressure
- **5-Day Forecast** - Detailed weather predictions for the upcoming week
- **Weather Details** - Air quality, UV index, visibility, sunrise/sunset times
- **Favorite Cities** - Save and quickly access your frequently searched cities
- **Responsive Design** - Optimized for desktop, tablet, and mobile devices
- **Modern UI** - Glass-morphism design with smooth animations
